## 🚀 Обо мне

- 💻 **Специализация:** Backend-разработка (Python), проектирование REST API, алгоритмы и машинное обучение.
- 🏗 **Архитектура:** На практике применяю Clean Architecture, Repository Pattern, Dependency Injection и принципы SOLID.
- 📈 **Данные и ML:** Увлекаюсь анализом данных и внедрением ML-моделей в продакшн-окружение. Регулярно решаю задачи на LeetCode для поддержания алгоритмической базы.
- 🎯 **Мой подход:** Пишу код не так, чтобы он "просто работал", а так, чтобы его было легко читать, тестировать и масштабировать через год.
